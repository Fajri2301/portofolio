STUDI KASUS 02 / MOBILE APPLICATION (FLUTTER 3.44, DART 3.12 & GO API)

SUKASARI MOBILE, SIPRANA & fintech flutter apps

Overview: Pengembangan ekosistem aplikasi mobile lintas platform menggunakan Flutter 3.44 (Dart 3.12) yang terintegrasi dengan backend Laravel Sanctum dan Go (Golang) REST API, meliputi Sukasari Mobile (Layanan Warga & RT), SiPRANA & SiGULER (Pramuka Digital Kwarran), Danantara Digital Bank, serta Aplikasi Toko Emas Digital.

My Role (Peran Saya)

Mobile Application & Backend API Developer (Arsitektur layar Flutter, penyimpanan token terenkripsi, konsumsi REST API Sanctum & Golang, serta pengujian widget)

Technology (Tech Stack)
  • Flutter 3.44.2
  • Dart 3.12.2
  • Go (Golang) REST API
  • Sanctum Bearer Auth
  • Flutter Secure Storage
Domain & Repository

Backend: sukasari.id | GitHub: Fajri2301 (4 Public Repos Mobile & Go)

Portal & API: sukasari.id Repo: Danantara Mobile (Dart) Repo: Toko Emas (Flutter) Repo: Backend Toko Emas (Go) Repo: Backend E-Money (Go)

Problem (Tantangan)

Ketua RT dan warga Desa Sukasari membutuhkan akses cepat dari ponsel untuk memverifikasi status kependudukan (NIK 16 digit) dan mengajukan pembaruan Kartu Keluarga tanpa harus bolak-balik ke balai desa. Sementara itu, anggota Pramuka Penegak memerlukan aplikasi terpadu (SiPRANA) untuk memantau Nomor Tanda Anggota (NTA), poin keaktifan, kehadiran QR, dan pencapaian SKU/SKK.

Solution (Solusi Arsitektur)

Membangun aplikasi klien Flutter dengan autentikasi berbasis token (flutter_secure_storage) dan unggah dokumen kamera/galeri (image_picker) yang berkomunikasi dengan endpoint /api/v1 pada Sukasari Mobile, serta merancang microservice Go (`be-tokoemas-golang` dan `be-emoney`) untuk menangani mutasi saldo dompet digital dan katalog harga emas secara ringan.

Features (Fitur Utama Terverifikasi)

  • Sukasari Mobile (`sukasari_app`): Cek NIK publik tanpa login, portal baca Berita Desa Sukasari Kecamatan Rajeg, serta modul khusus RT untuk melihat daftar KK/warga dan mengirim pengajuan perubahan data beserta lampiran dokumen.
  • SiPRANA & SiGULER Kwarran: Kartu Tanda Anggota (NTA) digital, pantauan poin keaktifan dan total kehadiran, pemindai QR presensi kegiatan, serta menu progres SKU, SKK, dan materi kepramukaan.
  • Danantara Bank & FajriDigitalBank: Antarmuka dompet digital, mutasi rekening, top-up saldo, dan integrasi dengan layanan backend Go E-Money.
  • Aplikasi Toko Emas Digital: Katalog produk emas real-time, kalkulasi gramasi pembelian, dan manajemen keranjang transaksi melalui Go REST API.

Outcome & Pengujian

Menghadirkan pengalaman pengguna lintas platform yang konsisten dengan pemisahan jelas antara mode publik dan mode terautentikasi:

Kualitas Kode Flutter: flutter analyze bersih dari isu statis dan didukung 29 pengujian otomatis (widget & unit test) pada aplikasi sukasari_app.
